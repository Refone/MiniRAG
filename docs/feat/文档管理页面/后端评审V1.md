1. 当前 Minio 数据库中储存不同文件的路径风格不一致:
   1. 图片: minirag/markdown-images/<file_name>/xxx.png
   2. 文档: minirag/final-markdowns/<task_id>/<file_name>/xxx.md
   3. 原始文档: minirag/origin-files/<task_id>/<file_name>/xxx.pdf
   4. chunks文件: minirag/chunks-json/<task_id>/<file_name>/xxx.json

2. 我希望能统一路径风格，移除 task_id 这一层级，使得所有文件的路径都遵循 minirag/<file_type>/<file_name>/xxx.<ext> 的格式。

3. 当前库内数据不需要考虑，都是测试数据。需求实现过程中可随意清库，不必考虑数据兼容与迁移。
