# V1 评审意见

当前的视觉风格我很喜欢，在当前的风格下，我觉得可能要走一点“回头路”

1. Item 内容重新调整:
   1. Item 中的摘要信息不要了，展开按钮也不需要了。
   2. 标题信息下面文字显示原始文档类型 “pdf ｜ markdown "
   3. 三按钮：pdf、切块文件、删除，从右侧标题区放回 Item 里面。
   4. pdf 按钮，如果是 markdown，pdf 按钮隐藏。如果原始文档是 pdf，还是点击新标签页预览原始 pdf。

2. 右半区标题区：
   1. 三按钮移除（移动到了左半区 Item 里面）
   2. 下面的文档类型、关键词、body-info 元素里面的 chunks 信息统统移除。
   3. mode-toggle 开关变成三档开关：原文 ｜ 切块 ｜ 特征。
      1. 【原文】即现在的 markdown 模式
      2. 【切块】即现在的 chunks 模式
      3. 新增【特征】，里面显示文档的关键词、以及摘要（这是一个新的子页面）
      4. toggle 开关文字位置、交互、UI 特征，参考 markdown-splitter 设计，可照抄。
   4. 综上，右半标题区目前包含元素有：文档标题 ph-title、mode-toggle 开关

3. 综合风格：当前色彩区分度较低，一些边界看不清楚，可适当，一点点，调整配色（这一点不要太激进，因为当前配色我也很喜欢）。

4. 右下角的 toast 移动到左下角，因为左边操作时，用户注意力在左侧，不宜在右侧出现提醒。并且稍微远离边界一点。
