> 状态：已完结（历史快照） · 文中 `src/`、`web/` 为 2026-11 目录改名前的路径，当前对应 `backend/`、`frontend/`；代码现状以仓库为准。索引见 [docs/feat/README.md](../README.md)。

1. 新增目录 MiniRAG/web/dev
   - 用于存放开发过程中使用的临时文件、调试工具或组件展示页面，如 components-gallery。
   - 把组件画廊和相关代码放到这个文件夹中。
   - 写一个 MiniRAG/web/dev/components-gallery.html, 独立页面，可直接在浏览器中打开，用于展示和调试组件。

2. 必要的开发工具或临时文件也应放在 MiniRAG/web/dev 目录下，不将任何非业务逻辑放在 MiniRAG/web/src 中。
3. 在 MiniRAG/web/dev 目录下创建 clean_cache.py 脚本, 用以清理浏览器缓存。本轮重构不考虑旧缓存迁移，直接清理即可。

4. [方案实现.md](../Session-MVVM/方案实现.md) 中的 BUG003 无需看护，已用偏移归零方案处理。
5. 取消 components-gallery 的设计。下一步我们将使用 storybook 完成组件展示和调试。第一轮重构实现去除这个子需求。
