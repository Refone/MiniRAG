# 页面美化 · 方案设计

**范围**：只改视觉层——配色、表面材质、阴影、圆角、状态色、图标；**不改**布局尺寸、交互流程、数据链路。
**参考**：Dark = [DeepSeek Harness 文档站](https://deepseek-harness.github.io/deepseek-harness/develop/basic/publish)（VitePress 深色）；Light = 本地 [`tools/markdown_chunks_viewer.html`](../../../tools/markdown_chunks_viewer.html)。

## 1. 视觉方向

一句话：**把 7 处装饰性渐变收成 0，把 4 档阴影收成 2 档（+1 个分段 thumb 控件阴影）并限制在 3 层，把 3 套蓝收成 1 套 indigo，把写死的语义色改成随主题成对的 text / soft 色。**

| 原则 | 做法 |
| --- | --- |
| 用表面分层，不用阴影堆叠 | 画布、导航、卡片三档纯色；暗色靠 +5% 明度抬升卡片，而不是加阴影 |
| 单一强调色 | Light `indigo`、Dark `periwinkle`；强调色同时承担链接、主按钮、选中态、焦点环，删除第二品牌色和独立 info 蓝 |
| 扁平但有层次 | 主卡片允许 1px 边框 + 极轻阴影；卡片内部元素一律用底色/描边区分，不再叠加投影 |
| 语义色成对出现 | 每个状态 = 语义文字色 + 同色系浅底；不使用饱和色块 + 白字 |
| 微调而非重排 | 主结构宽度、断点、桌面间距、动画时长保持现状；只收紧圆角（16→12、20→16），并处理窄屏输入区换行 |

### 使用规则

1. **纯色禁令**：除输入区底部功能性遮罩外，任何背景、按钮、Logo、头像都不使用渐变；加载态用透明度脉冲，不用扫光渐变。
2. **强调色分工**：`--accent` 只用于文字/图标；`--accent-fill` 只用于实心按钮；`--accent-soft` 只用于选中底、激活底、徽章底；三者不混用。
3. **软色底上只用深一档语义色**：如 `success-soft #dcfce7` + `success #15803d`，不再出现白字。
4. **语义色不作为唯一信号**：状态徽章同时有文字标签 + 6px 圆点；进度节点同时有图标 + 文案。
5. **弱文本仅装饰**：`text-3` 只用于分隔符、极次要计数，不承载必读信息。
6. **禁止彩色投影**：删除 Logo、发送按钮的蓝色光晕；阴影只允许中性黑。

| L1 主面板 | 左右两张主面板 | `surface` + 1px `border` + `shadow-1` | `surface` + 1px `border`，**无阴影** |
| L1 卡内块 | 切块卡、特征卡、导入任务、文档条目 | `surface` / `surface-2` + 1px `border`，**无阴影** | 同左 |
| L2 悬浮 | 输入卡片 | `surface` + 1px `border-strong` + `shadow-1` | 同左，阴影透明度降低 |
| L3 遮罩 | 确认弹窗、toast | `shadow-2` + `mask` | `shadow-2` + 更深 `mask` |

约束：**卡内块不再浮起**（文档条目、按钮、徽章、切块卡、关键字 chip 全部用底色/描边）；同一屏 L2 + L3 合计不超过 2 个；不用 blur / glass / 彩色 glow。

```css
--shadow-1: 0 1px 2px rgba(15, 23, 42, .06);   /* dark: rgba(0,0,0,.35) */
--shadow-2: 0 8px 24px rgba(15, 23, 42, .12), 0 2px 6px rgba(15, 23, 42, .06);
                                                /* dark: 0 12px 32px rgba(0,0,0,.5) */
--shadow-seg: 0 1px 3px rgba(15, 23, 42, .16), 0 0 0 1px rgba(15, 23, 42, .04);
```

### 字体与排版

- 字体栈：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`，优先系统字体，解决 Windows 下 Segoe UI 与雅黑混排不一致。
- 字号保持现状：对话 15px / 1.7，切块正文 14px / 1.7，控件 13px，元信息 11–12px。
- 标题加 `letter-spacing: -0.01em`；正文不使用纯黑/纯白（`on-accent` 除外）。
- 全局 `::selection` 使用 `accent-soft` 底 + 主文本色；滚动条 thumb 用 `border-strong`，宽 8px。

现状彩色 Emoji 会把刚压低的色彩重新拉高。建议换成 16px 单色线性 SVG，颜色继承 `currentColor`：

- 导航：对话气泡 / 书本；主题：太阳 / 月亮；Bot：四角星；空态：文件 / 收件箱托盘；上传：箭头入托盘。

- 预览 HTML 已按 SVG 方案实现；只影响视觉，不动布局与交互。

## 8. 取舍与边界

- **换色相**：品牌从 azure `#1aa7ff` 换成 indigo `#4f46e5`（浅色）与 periwinkle `#a8b1ff`（深色）。这是本次观感变化最大的一项，但也是参考配色的核心；布局完全不动，可通过 `--accent*` 一处回退。
- **深色不靠阴影**：暗色下 `sh-2` 几乎不可见，改为「卡片比画布亮一档 + 1px 描边」，更接近参考站。
- **输入区渐隐保留**：它是防止消息压住输入卡的功能遮罩，不属于装饰渐变；若严格要求「零渐变」，可改为输入卡片下方实底栏，但会改变现有悬浮布局。
- **图片去框、保留轻圆角**：Markdown 图片去掉阴影、边框和外框底色，保留 `--r-sm` 6px 圆角，按原始比例直接铺在正文中；白底说明书图不再加描边，避免「图外套框」。
- **图标替换可拆分**：颜色方案不依赖图标；先落色板也能得到 90% 的效果。
