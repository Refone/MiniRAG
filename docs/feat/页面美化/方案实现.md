## 2. 关键实现

### 2.1 Markdown 图片

- `.markdown-img` / `.markdown-img-link`：去阴影、去边框、去外框底色，保留 `--r-sm` **6px** 圆角。
- 该规则同时作用于对话页、文档「原文」「切块」，图片 lazy-load 与点击打开原图行为不变。

### 2.2 发送贴底

```text
点击发送 / Enter
  → forceBottomRef = true
  → 消息提交后 rAF 设置 scrollTop = scrollHeight，并置 pinned = true
  → 流式增量、进度展开、图片重新布局继续跟随
  → 用户主动上翻后 pinned = false，停止跟随
```

- `ResizeObserver(.chat-inner)` 捕获图片懒加载、进度展开等高度变化；贴底时自动补滚。
- 输入卡高度变化（`onHeightChange`）同样触发贴底校正。

### 2.3 回到底部按钮

- 滚动距离 >20px 时显示；32px 圆形，位于 composer 锚点右上方。
- `right: 11px` = composer 右 padding 10px + border 1px；两枚按钮同为 32px，中心与发送按钮对齐。
- 点击后隐藏并强制贴底；隐藏态设置 `aria-hidden` 和 `tabIndex=-1`，不进入 Tab 顺序。

### 2.4 设计决策与偏差

- **图标单色化**（方案中 P1 可选项）已实现，与色板改造一并落地，未拆分为两次提交。
- **删除确认按钮**使用 `danger-soft` + 语义色文字，而非实心 danger + 白字，避免深色下对比不足，并符合「白字仅 accent 实心按钮 / Logo」的规则。
- **图片圆角**按验收反馈从 12px → 5px → 最终 6px，并归入 `--r-sm`；未保留一次性 `--r-img` 令牌。
- **回到底部按钮**为验收阶段追加的交互，不在原始 PRD 内。
- 主布局、360/800/768 宽度、940/780/720 断点、滚动恢复、SSE 生命周期均未改；窄屏仅新增 footer 换行、品牌副标题收起与回底按钮。
