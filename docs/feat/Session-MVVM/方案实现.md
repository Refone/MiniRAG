## 1. 实施概述

按方案设计-V0.md §6 的实施顺序完成 V0 全部六步：

1. `App.tsx` 双 `<Activity>` 保活（React 19.3，`@types/react` 19.3.0 类型可用）；
2. 安装 `zustand@5.0.16`，新增 `requestCache.ts` / `imageCache.ts`，`PreviewMode` 移入 `types.ts`，`api.ts` 收敛 4 个 HTTP 函数；
3. chatStore + ChatPage 改造（SSE 上移，页面改订阅）；
4. docsStore + ImportPage 改造（上传 SSE 上移，失效点收敛）；
5. `Markdown.tsx` 图片走 `useImageUrl`；后端 `/api/files` 加 `Cache-Control`；
6. zustand persist 配置（partialize 白名单 + version 1）。

## 3. 核心实现点

### 3.1 保活与 effects 守卫

- 两页常驻 `<Activity>`：隐藏页 `display:none`，state 与 DOM 保留（滚动位置、输入草稿、预览模式、左滑视图等视觉状态零代码保留）；
- Activity 切回 `visible` 会**重建 effects**，因此两处 effect 必须加守卫（设计 §8-1）：
  - ChatPage 滚动：贴底跟随模式（`pinnedRef` 仅由真实滚动事件更新）——贴底时发送/流式跟随到底，上翻阅读后不强制滚动，切回保持原位置；
  - ImportPage ChunkRail：`prevSelKeyRef` 守卫，仅真正切换文档/预览模式时重置高亮。

### 3.2 SSE 上移（任务跟踪）

- 查询流：`chatStore` 模块级 `esRef`，`send()` 内建连，progress/delta/final/`__close__`/error 回调写 store；页面切走/隐藏/卸载均不 close；
- 上传流：`docsStore` 模块级 `esMap: Record<fileId, EventSource>`，`uploadFiles()` → `postUpload` → `startSse()`；完成回调 `updateFile(completed)` + `invalidateCache("docs:list")` + 去重后自动刷新列表；
- 页面内原"卸载关闭 SSE"的 cleanup 已删除。

### 3.3 请求缓存与失效

- key 约定：`docs:list`（TTL 30s）、`docs:detail:{docId}`（TTL 5min）、`history:{sessionId}`（TTL 30s）；
- 失效点（收敛在 store 动作内）：上传完成 → `docs:list`；删除 → `docs:list` + `docs:detail:{docId}`；清历史 → `history:{sessionId}`；
- 竞态保护：`selectDoc` 快速连选时校验 `selectedId === docId` 才落详情。

### 3.4 图片缓存

- 站内判定：`/api/files/**` 或 `API_BASE + /api/files/**`；外部 http(s) 原样渲染；
- `useImageUrl`：命中直接返回 objectURL；未命中先按原 URL 渲染，后台 fetch→blob→objectURL 就绪后切换（并发去重，失败静默回退）；
- refs 引用计数保证展示中的图片不被 LRU 回收；淘汰时 `revokeObjectURL`；
- 后端 `Cache-Control: public, max-age=86400, immutable` 兜底跨刷新场景。

### 3.5 持久化

- `kb-chat-store`：partialize `{ enableWebSearch, enableHyde }`，version 1；
- `kb-docs-store`：partialize `{ previewMode }`，version 1；
- `sessionId` 沿用 `kb_session_id`（现状机制，未迁移）。

## 5. 待人工回归清单

以下场景需在浏览器（localhost:5173）人工验证，逐条勾选：

- [ ] 会话页提问 → 切文档页 → 切回：消息、滚动位置保持，流式回答仍在推进（SSE 未断）；
- [ ] 文档页选文档看预览 → 切对话 → 切回：列表、详情、预览模式、滚动保持，Network 面板无重复 `/api/docs/detail` 请求；
- [ ] 上传文件后立刻切走 → 切回：进度持续更新，完成后列表自动刷新、toast 可见；
- [ ] 会话页上翻历史 → 切走再切回：仍停留在原位置（不跳底部）；贴底时发送 → 跟随到底；
- [ ] 刷新页面：开关 / 预览模式保留；图片经 HTTP 缓存加载（Network 面板 `from disk cache`）；
- [ ] 回归：清空历史、删除文档（含预览中删除）、PDF/切块文件外链、服务连接状态点、主题切换。
