## 路径映射

| 文档中的旧路径 | 当前路径 |
| --- | --- |
| `src/**` | `backend/**` |
| `web/**` | `frontend/**` |
| `web/src/**` | `frontend/src/**` |

旧文档中已经失效的路径（如 `src/processor/**`、`src/utils/**`）不要强行映射到现存文件；
它们只说明当时的代码位置，当前实现请以 `backend/`、`frontend/` 的实际文件为准。

## AI 阅读协议

1. 先读本表，确认目标需求是「当前有效」还是「历史」。
2. 当前代码事实去 `backend/`、`frontend/` 里搜索；不要从历史文档推断当前文件是否存在。
3. 历史文档只用于查决策与先例；路径按上表映射。
4. 新方案、新 PRD 一律写 `backend/...`、`frontend/...`，并在本表登记。
